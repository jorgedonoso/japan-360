# Japan 360

Immersive 360° gallery of my journey through Japan’s 47 prefectures.

## Tech Stack

- Next.js
- TypeScript
- Photo Sphere Viewer
- Tailwind CSS

## ENV

```bash
NEXT_PUBLIC_IMAGES_URL=
NEXT_PUBLIC_GA_ID=
NEXT_PUBLIC_ENVIRONMENT=
```

## Run

```bash
npm install
npm run dev
```
